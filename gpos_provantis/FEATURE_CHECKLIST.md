# GPOS Provantis User Feature Checklist

This checklist is a simple guide for users. It covers the main features of the app from login to dashboard, settings, reports, and daily operations.

Use this as a quick user guide and training checklist.

## 1. Login and startup

- [ ] Open the app.
- [ ] Wait for the startup screen to finish loading.
- [ ] Enter the correct username.
- [ ] Enter the correct password.
- [ ] Tap Login.
- [ ] If setup is not complete, go to setup first.
- [ ] If prompted, complete the terminal setup before continuing.
- [ ] Confirm the app loads the dashboard successfully.

## 2. First-time setup

- [ ] Open the setup screen.
- [ ] Enter the server or domain address.
- [ ] Select the protocol if required.
- [ ] Enter the port number if required.
- [ ] Enter the branch details.
- [ ] Enter the POS details.
- [ ] Save the setup.
- [ ] Restart or reopen the app if needed.
- [ ] Confirm setup saved successfully.

## 3. Dashboard basics

- [ ] Open the Dashboard screen.
- [ ] Check the product area.
- [ ] Use the barcode field to scan or enter a code.
- [ ] Add items to the cart.
- [ ] Review the cart list.
- [ ] Remove an item if needed.
- [ ] Change the quantity of an item.
- [ ] Confirm the total before payment.
- [ ] Tap Charge to continue.
- [ ] Use the Others button for extra actions.
- [ ] Use the Start shift button when beginning work.
- [ ] Use the End shift button when closing work.

## 4. Add items to a sale

- [ ] Scan a product barcode.
- [ ] Or choose a product from the product list.
- [ ] Verify the item is added to the cart.
- [ ] Add more quantity when needed.
- [ ] Remove the item if the customer changes their mind.
- [ ] Continue adding items until the sale is complete.
- [ ] Review the final cart before payment.

## 5. Discounts

- [ ] Open the cart and locate the discount area.
- [ ] Tap Add discount.
- [ ] Choose an available discount.
- [ ] Confirm the discount selection.
- [ ] Check that the discount amount is deducted from the total.
- [ ] If a discount needs customer information, enter it.
- [ ] Remove the discount if needed.
- [ ] Confirm the final total before charging.

## 6. Payment process

- [ ] Tap Charge.
- [ ] Choose the payment type.
- [ ] If using cash, enter the amount received.
- [ ] If using e-payment, confirm the payment method.
- [ ] If using split payment, divide the amount correctly.
- [ ] Confirm the total matches the customer payment.
- [ ] Complete the payment.
- [ ] Confirm the receipt prints.
- [ ] Give the receipt to the customer.

## 7. Cash payment

- [ ] Select Cash as payment method.
- [ ] Enter the amount given by the customer.
- [ ] Check the change due.
- [ ] Return the correct change.
- [ ] Confirm the sale.
- [ ] Print the receipt.

## 8. E-payment

- [ ] Select E-payment.
- [ ] Choose the payment method or confirm the e-payment option.
- [ ] Enter the amount to be paid.
- [ ] Confirm the transaction.
- [ ] Check that the sale is complete.
- [ ] Confirm the receipt prints.

## 9. Split payment

- [ ] Tap Split payment.
- [ ] Choose the split payment flow.
- [ ] Enter the first payment amount.
- [ ] Enter the second payment amount.
- [ ] Make sure the total matches the sale.
- [ ] Confirm the payment.
- [ ] Check that the receipt prints correctly.

## 10. Others menu

- [ ] Tap Others from the dashboard.
- [ ] Open Reprint Receipt if needed.
- [ ] Open Refund if processing a return.
- [ ] Open Send e-receipt if sending a digital receipt.
- [ ] Open Cash drop to record cash removal.
- [ ] Open Cash reports to check cash activity.
- [ ] Open Receipts to view past sales receipts.
- [ ] Open Reports to review sales and shift information.
- [ ] Open Sold items to view item sales.
- [ ] Use Sync data when needed.
- [ ] Use Restart POS when required.
- [ ] Open the cash drawer if needed.

## 11. Reprint receipt

- [ ] Tap Others.
- [ ] Select Reprint Receipt.
- [ ] Choose the receipt to reprint.
- [ ] Confirm reprint.
- [ ] Verify the receipt prints again.

## 12. Refund

- [ ] Tap Others.
- [ ] Select Refund.
- [ ] Find the relevant sale or item.
- [ ] Enter the refund amount or item details.
- [ ] Confirm the refund.
- [ ] Check the receipt or refund record.

## 13. Send e-receipt

- [ ] Tap Others.
- [ ] Select Send e-receipt.
- [ ] Enter the customer email address.
- [ ] Review the receipt details.
- [ ] Send the e-receipt.
- [ ] Confirm it was sent successfully.

## 14. Cash drop

- [ ] Tap Others.
- [ ] Select Cash drop.
- [ ] Enter the amount to drop.
- [ ] Choose the correct reason if prompted.
- [ ] Confirm the cash drop.
- [ ] Check the drop record or printed slip.

## 15. Open cash drawer

- [ ] Tap Others.
- [ ] Select Open cash drawer.
- [ ] Confirm the action.
- [ ] Use the drawer only when needed.
- [ ] Close the drawer after use.

## 16. Receipt and sales history

- [ ] Tap Others.
- [ ] Open Receipts.
- [ ] Look for the correct receipt.
- [ ] Review details of the transaction.
- [ ] Open Reports for summary information.
- [ ] Open Sold items to check individual sold products.
- [ ] Use the list as needed for customer concerns or sales review.

## 17. Shift management

- [ ] Start shift before taking sales.
- [ ] Confirm the drawer count if required.
- [ ] Continue processing customer sales.
- [ ] Review shift status during the work day.
- [ ] End shift at the close of the day.
- [ ] Confirm the closing count if prompted.
- [ ] Save the final shift report.

## 18. Reports

- [ ] Tap Others.
- [ ] Open Reports.
- [ ] Review sales totals.
- [ ] Review cash summaries.
- [ ] Review shift summary information.
- [ ] Use the report to prepare for closing the day.
- [ ] Confirm the report matches the actual cash and sales.

## 19. Settings

- [ ] Go to Settings from the app navigation.
- [ ] Open the Printers section.
- [ ] Check that the printer is connected and assigned.
- [ ] Open the Transactions section.
- [ ] Review transaction-related settings.
- [ ] Open the POS Config section.
- [ ] Confirm POS information is correct.
- [ ] Open the Email section.
- [ ] Configure email settings if needed.
- [ ] Open the Sync section.
- [ ] Run syncing when required.
- [ ] Open the System section.
- [ ] Review the system settings.
- [ ] Open the Theme section.
- [ ] Change the display theme if needed.
- [ ] Open the Users section.
- [ ] Review user-related settings.
- [ ] Open the Counter Display section if used.
- [ ] Check the About section for version or app info.

## 20. Printer settings checklist

- [ ] Confirm the right printer is selected.
- [ ] Check if the printer is Wi-Fi or USB.
- [ ] Confirm the printer is connected.
- [ ] Test print a receipt.
- [ ] Check if the cash drawer is enabled if needed.
- [ ] Confirm the printer is active before the shift begins.

## 21. Daily user checklist

- [ ] Log in.
- [ ] Open the shift.
- [ ] Check printer status.
- [ ] Make sure cash drawer is ready if needed.
- [ ] Process sales.
- [ ] Apply discounts when required.
- [ ] Accept payment.
- [ ] Print receipts.
- [ ] Use Others menu when needed.
- [ ] End shift at the close of work.
- [ ] Review reports and cash totals.

## 22. Final user reminder

- [ ] Always open the shift before selling.
- [ ] Always check the total before charging.
- [ ] Always confirm the payment method.
- [ ] Always print or send the receipt.
- [ ] Always end the shift properly at the close of the day.
- [ ] Always report any printer or cash issues immediately.

This checklist is intended as a practical guide for staff using the app every day.
